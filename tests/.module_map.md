# Tests Module Map

## Scope
- Playwright E2E runtime for the critical JIMPITAN MVP user journeys.
- API, web, protected-route, public-page, and optional Telegram webhook smoke checks.
- Deterministic test fixture contracts with explicit seed and cleanup boundaries.
- Production-readiness and security-check contracts.

## Files
- `tests/.module_map.md`: local testing map.
- `tests/e2e/types/e2e.types.ts`: critical journey, runtime config, fixture, API client contracts, and journey matrix.
- `tests/e2e/support/env.ts`: E2E env loading, safety checks, schema push, and state path helpers.
- `tests/e2e/support/fixtures.ts`: deterministic seed and cleanup implementation.
- `tests/e2e/support/api-client.ts`: API helper client for setup, validation, and cleanup flows.
- `tests/e2e/support/global-setup.ts`: Playwright database setup and seed entrypoint.
- `tests/e2e/support/global-teardown.ts`: Playwright cleanup entrypoint.
- `tests/e2e/critical-journeys.spec.ts`: Playwright critical MVP user journey implementation.
- `tests/smoke/api-smoke.spec.ts`: API smoke implementation.
- `tests/smoke/web-smoke.spec.ts`: web smoke implementation.
- `tests/smoke/telegram-webhook-smoke.spec.ts`: Telegram webhook smoke implementation.

## Flow
1. Load safe E2E env from non-production variables.
2. Assert the target database and hosts are test-only.
3. Seed one tenant, RT membership, officer/admin principal, area, house, resident, cash account, approval policy, and public report fixture.
4. Execute critical journeys through the browser and API helpers.
5. Validate finance posting, export availability, RBAC/tenant isolation, and public report safety.
6. Clean all test-owned records by deterministic run id.
