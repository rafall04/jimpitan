Dashboard Layout

Desktop layout uses persistent sidebar, compact top command area, KPI strip, chart area, validation queues, and operational lists.

Linear + Supabase density

Primary dashboard zones

  • Top: RT scope switcher, date range, global search, create action.
  • Middle: cash, collection, outstanding, approval widgets.
  • Lower: cash flow chart, collection route status, recent audit.
  • Right inspector: contextual detail for selected queue item on wide screens.

Navigation structure

  • Overview
  • Warga: residents, houses, areas, imports
  • Jimpitan: schedules, collection sessions, validation
  • Finance: transactions, categories, ledgers, approvals
  • Reports, Telegram, Audit, Settings

Typography

Inter/system sans. 14px base. 16px mobile form fields. No viewport-scaling body text.

Radius

7-8px for controls and cards. 12px only for large app shells and browser frames.

Spacing

4px rhythm. Dense dashboard spacing, generous mobile tap areas with 44px minimum controls.
