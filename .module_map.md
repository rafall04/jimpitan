# Planning Module Map

## Scope
- This workspace currently contains planning artifacts, Prisma schema, a NestJS backend skeleton, Auth/RBAC foundation logic, Tenant/User/Membership foundation logic, Residents/Houses/Areas module logic, Jimpitan collection workflow logic, Finance/Ledger foundation logic, Expense Approval workflow logic, Notification workflow logic, Telegram Bot integration logic, Reporting Engine and Export Engine foundation logic, Public Transparency API logic, background worker foundation logic, a Next.js frontend shell, implemented frontend Residents/Houses/Areas UI, implemented frontend Jimpitan operational UI, implemented frontend Finance/Ledger/Approval/Report Export UI, implemented public transparency UI, and VPS-friendly Compose/Nginx/PostgreSQL/Redis deployment foundations.
- Email provider delivery integration, remaining private settings frontend business pages, seed data, migrations, payment gateway, and analytics dashboards remain out of scope until explicitly approved.

## Flow
1. Review visual planning companion.
2. Review technical architecture.
3. Review Prisma database schema.
4. Review backend skeleton.
5. Confirm or revise product scope, UX direction, architecture, schema, and backend boundaries.
6. Write approved design spec.
7. Write implementation plan.
8. Start next approved workflow implementation after Auth/RBAC foundation verification.
