# Public Reports Feature Map

## Scope
- Owns unauthenticated public transparency UI helpers for `/`, `/reports`, `/reports/monthly`, `/reports/collections`, `/announcements`, and public CSV export links.
- Uses backend public-safe report endpoints only: `/reports/public/:rtCode/summary`, `/monthly-finance`, `/metadata`, `/announcements`, and `/exports/*.csv`.
- Keeps browser-rendered public data limited to organization metadata, aggregate cash totals, monthly totals, category totals, report metadata, and public announcement copy.
- Does not call authenticated dashboard proxy routes, expose resident data, render phone-like strings, expose audit logs, or add export/payment/analytics behavior.

## Files
- `types.ts`: public-safe API response and pagination contracts.
- `format.ts`: Indonesian date/currency formatting, public RT/month/search route sanitization, month-window helpers, and phone-like copy redaction.
- `api.ts`: direct unauthenticated backend public report fetch helpers, public CSV export URL builders, explicit `credentials: 'omit'`, recursive private-field guard, and phone-like string redaction.
- `components.tsx`: server-renderable public report page sections, loading skeletons, charts, tables, empty states, and share links.
- `*.test.ts(x)`: Vitest coverage for API safety, formatting, filtering, SSR render smoke, and no-private-field rendering.

## Flow
1. Public routes resolve `rt` and `month/search/page` query parameters through `format.ts` before API calls; missing RT code renders a safe configuration empty state instead of using a hardcoded tenant.
2. API helpers call public backend report endpoints with no cookies, bearer token, or `X-Tenant-Id` header.
3. `api.ts` rejects private-shaped payload keys before returning typed public data.
4. Views format money as IDR, dates/months in Indonesian locale, expose public CSV download links, and redact phone-like strings from public announcement copy.
5. Collection UI derives only explicitly collection-like income categories from the public monthly finance endpoint because no public outstanding-detail endpoint exists.
6. Public CSV links point to unauthenticated backend public export endpoints and never to the authenticated dashboard proxy.
