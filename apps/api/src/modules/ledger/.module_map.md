# Ledger Module Map

## Scope
- Implements tenant-scoped append-only ledger reads, ledger entry detail, and ledger-derived balance contracts.
- Ledger writes are owned by the finance posting transaction boundary. Expense approvals, reports, Telegram handlers, public pages, payment gateway logic, and analytics dashboards are not implemented.

## Files
- `ledger.module.ts`: module imports, controller/service registration, and service export.
- `ledger.tokens.ts`: repository provider token.
- `domain/ledger.types.ts`: ledger entry, account balance, and append input shapes.
- `application/ledger.commands.ts`: ledger query and request metadata contracts.
- `application/ledger.service.ts`: ledger list/detail/balance use cases and tenant-scoped not-found handling.
- `infrastructure/ledger.repository.port.ts`: append-only ledger read persistence port.
- `infrastructure/prisma-ledger.repository.ts`: Prisma implementation for ledger listing, detail, and latest-balance reads.
- `presentation/ledger.controller.ts`: `/api/v1/ledger` read routes with RBAC metadata.
- `presentation/dto/ledger-query.dto.ts`: class-validator and Swagger DTO for ledger filtering.

## Flow
1. Ledger reads are tenant-scoped by `actor.rtId` and guarded by `transactions.read`.
2. Finance posting is the only writer and writes ledger rows inside the same transaction as transaction posting.
3. Balance is derived from ledger entries and never from deleted or rewritten ledger rows.
4. Ledger rows are never physically deleted by application workflows.
