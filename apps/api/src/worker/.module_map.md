# Worker Module Map

## Scope
- Runs a NestJS application context without opening HTTP listeners.
- Drains database-backed report export jobs through `ReportsService.processPendingCsvExports`.
- Drains notification outbox Telegram deliveries through `TelegramService.processTelegramOutbox`.
- Redis is provisioned by Compose for shared infrastructure and future queue/rate-limit adapters; current durable job state remains in PostgreSQL outbox/export tables.

## Files
- `main.ts`: worker bootstrap, signal handling, app-context lifecycle, and graceful shutdown.
- `worker.module.ts`: DI boundary for config, Prisma, reports, notifications, and Telegram job dependencies.
- `worker.service.ts`: queue selection, batch limits, stale-job recovery cutoff, one-pass processing, wakeable polling loop, and health heartbeat.
- `worker.service.spec.ts`: worker orchestration tests.
